Installation guides

Choose your platform

The steps below explain what to expect. Downloads stay gated until signed installers are ready for public use.

macOS

For Mac computers · macOS 13+

Signing in progress
Not ready for public installation The current Mac preview is unsigned. Wait for the Developer ID signed and Apple-notarized installer; don’t bypass Gatekeeper for the preview.
  1. Download the verified DMG

    When available, download the signed Sasa VPN disk image from this page.

  2. Open the disk image

    Double-click the downloaded .dmg file to open its installer window.

  3. Move Sasa VPN to Applications

    Drag the app into Applications, then eject the mounted installer from Finder.

  4. Launch and approve the VPN setup

    Open Sasa VPN and follow macOS prompts to add its VPN configuration.

A signed and notarized release will appear here.

Windows

For Windows 10/11 · 64-bit

Private preview
Public download is gated The preview installer is unsigned and currently private. The public download will be enabled after a signed installer is prepared.
  1. Download the verified setup file

    Use the Windows download button here once a signed public installer is available.

  2. Run the installer

    Open SasaVPN-Setup.exe and follow the setup wizard. It installs for your Windows account.

  3. Choose your shortcuts

    You can add a desktop shortcut during setup. Sasa VPN also appears in the Start menu.

  4. Open Sasa VPN and sign in

    Launch the app and follow its prompts to finish setup and connect.

The public download will be posted here after signing.

Install only from a verified Sasa release

We’re keeping downloads gated while the desktop installers are prepared for public use. Don’t turn off macOS or Windows security checks to install an unsigned preview.

What the app does

Useful tools, without the clutter.

Everything you need to choose your connection, bring a custom configuration, and manage VPN behavior from one place.

Core features

Take control of your connection

Different features, explained in one place. Actual protocol availability depends on the version and configuration.

01 · Connect

One-Tap Connection

Pick an available managed server and connect using the main power button. The app displays the actual connection state rather than a simulated status.

02 · Import

Custom VPN Profiles

Use your own compatible WireGuard or proxy configuration, separate from Sasa-managed servers.

03 · Protocols

Protocol Options

See the protocol options supported by your installation. Switching requires a working engine and configuration.

04 · Stability

Auto-Reconnect

Retry the connection after an interruption when this option is enabled and the operating system allows it.

05 · Safety

Kill Switch

Configure supported system-level traffic protection to reduce unintended traffic outside the VPN.

Popular help topics

Open the official release link for your device, install the application, then follow the permissions requested by the operating system. Installers will appear here once published.

Open Servers, select a server available for your account, return to Home, then press Connect. Wait until the app confirms that the VPN tunnel is connected.

Check your internet connection, confirm the selected server is available, and try reconnecting. If a custom profile is used, confirm its endpoint and credentials. Avoid repeatedly reconnecting if the network blocks VPN traffic.

Open Settings → My VPN Profiles → Import. Choose a supported file, link, or pasted configuration. Review the profile before connecting and only import configurations from trusted providers.

Supported device counts depend on your account's plan. Check your active plan details in the app for the current limit.

Open Settings → Connection Settings. Available options depend on the platform and version. Some kill-switch behavior requires operating-system-level configuration.
